# Architecture Decision Records (ADRs)

Short, dated records of *why* a non-obvious technical decision was made, so the
context isn't lost. Agents and new contributors should read these before
changing the areas they cover.

Format: one file per decision, `NNNN-short-title.md`, with Status / Context /
Decision / Consequences.
